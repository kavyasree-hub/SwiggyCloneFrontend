# Swiggy Clone - Frontend

A responsive food delivery website frontend inspired by the Swiggy platform. 
This project was developed to practice and demonstrate frontend web development 
skills using HTML and CSS.

## 🚀 Live Demo

https://drive.google.com/file/d/1nZ4YxhJbKcv3IiiiO3C_BlivCCOLeqw4/view?usp=sharing

## 📌 Project Overview

Swiggy Clone Frontend is a frontend development project that recreates the 
look and feel of a modern food delivery website.

The project focuses on creating a clean, responsive, and visually appealing 
user interface using HTML and CSS.

It includes sections for food ordering, restaurants, offers, and other 
elements commonly found on food delivery platforms.

> **Note:** This is an independent frontend practice project and is not 
> affiliated with, sponsored by, or officially connected with Swiggy.

## ✨ Features

- 🍔 Food delivery landing page
- 🏪 Restaurant and food sections
- 🔍 Search interface
- 📍 Location-based interface
- 🛒 Food ordering interface
- 🎁 Offers and promotional sections
- 📱 Responsive layout
- 🎨 Swiggy-inspired user interface
- 🧭 Navigation bar
- 🖼️ Food images and visual sections

## 🛠️ Technologies Used

- HTML5
- CSS3
